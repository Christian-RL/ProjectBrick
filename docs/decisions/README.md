# Architecture Decision Records

Use an Architecture Decision Record for choices that constrain later implementation, data formats, provider selection, persistence compatibility, licensing, deployment, or security.

Name records `NNNN-short-title.md`, beginning with `0001`. Copy `0000-template.md`, replace every placeholder, and link the ADR from the pull request that implements it.

Allowed statuses are **Proposed**, **Accepted**, **Superseded**, and **Rejected**. Never rewrite an accepted decision to hide history; add a new ADR and mark the old record as superseded.
